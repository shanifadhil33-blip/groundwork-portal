## Dates, localization and isolation

The database reset instant anchors the workspace's local date. Visits, due dates, reports, leave, ratings, draft bills, document dates and past decision times derive from that date. Decision creation precedes consumption by one minute, and both undone decisions record their later undo time. Decisions fall one or two days before reset. Future reset tests cross the leap day boundary and a new year, including a UTC date that is already the next day in Dubai. Random IDs are sandbox specific; the cast, counts, history bands and relative cases rebuild consistently.

Dune prose uses the same LANG12 exact fixture allowlist and Translator path as Ridgeline. `lib/demo-dune-harbour-copy.ts` lists the permitted sample text. Gulf Arabic fixture translations ship in that demo copy module, covering job titles and descriptions, report reasons and work, asset labels and locations, leave, ratings, suggestion text, money notes, price comments and the new permit and decision text. Reused Ridgeline document titles retain their existing translations. Slice 2 adds no fixture translations to `public/i18n` files. Names, brands, addresses and editable values remain data. Changed notes and real workspace records stay verbatim. Other languages use the existing translation path; complete offline Dune dictionaries for those languages remain future work. Ridgeline's existing offline dictionaries and tests retain their scope.

All people remain male, and seeded prose contains no dashes. No migrations, schema changes or real logins are introduced. Ridgeline's PDF generator is extracted unchanged into `lib/fixture-documents.ts` for both fixtures; Ridgeline's seeded data and PDF bytes retain their existing behavior. Seeding uses existing table inserts and helpers, as Ridgeline does, rather than notification sending service calls. `lib/services/demo.ts` is unchanged: Dune still requires server flag `DEMO_DUNE_HARBOUR=1`; without it judges get the existing Ridgeline demo. Both companies retain their existing six hour sandbox expiry and reset paths.
